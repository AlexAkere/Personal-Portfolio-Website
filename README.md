Alex Akere | Software Developer Portfolio Webite

My personal portfolio website designed to showcase my software development projects, technical skills, and professional resume. 

##  Tech Stack
* **Structure:** Semantic HTML5
* **Styling:** CSS3 (Custom Properties, Flexbox, CSS Grid)
* **Interactivity:** Vanilla JavaScript (ES6+)
* **Hosting:** GitHub Pages
* **Design:** Custom Dark/Light theme with radial gradients

## Features
* **Responsive Layout:** Fully adaptive design for Mobile, Tablet, and Desktop.
* **Dark Mode System:** State persistence using `localStorage` so the user's preference is saved.
* **Project Showcase:** Dynamic grid layout for displaying GitHub projects.
* **Performance:** Optimized assets for fast load times and high Lighthouse scores.
